# 关键设计

## 输入与会话

`NavigationMachine` 只有 inactive、navigation、input 三态。键位使用硬件 key code，逐键保存首次 key-down 的吞下/透传归属，key-up 使用原归属。按住键不重复执行索引动作；临时输入返回前已透传的 key-down 仍对应透传 key-up。退出后的 tap 仅在有尚未释放的吞键时短暂保留以排空配对，其他按键直接透传，最后一键释放立即停用。

区域码使用 W/E/R；按钮首位 SADFHL、后续 SADFHJKLG。前缀存在时 J/K/G 不再滚动。Return 只作用于当前显示页的合法选择；不完整区域或按钮码不会误点默认控件。

控制队列处理输入和滚动 timer，不做 AX IPC。AX 队列串行扫描、校验及观察注册；布局队列计算编码与碰撞；主线程只测量字体、管理 AppKit 窗口及显示。每个会话、扫描、布局、动作有版本或取消标记。失效时保留边框可以表达选区身份，但旧按钮与滚轮位置不可执行。

## 一次扫描，多种范围

`ScanTraversal` 通过 `AXReading` 读取数据，可注入测试图。一次分片遍历同时收集角色、几何、祖先、滚动属性、按钮和浮层。第一片约 12 ms，其后约 40 ms，每片最多 160 工作项、每批 128 子节点；最多 7,000 节点、2,500 控件及约 1.5 秒累计工作。预算是软保护，单次 OS 调用可能超过预算。

聚焦路径影响子节点优先级，表格优先可见行，其他分支保留。没有矩形、禁用的包装层仍继续遍历。已识别菜单、sheet、dialog、popover、modal 的裁剪从浮层自身重新开始；点击校验也遵循这条边界。

区域优先真实滚动容器，补充 WebArea、大尺寸语义列表、导航/侧栏/主内容 landmark 和共同布局父节点中的相邻大型面板。列表及 landmark 仅在有同列滚动视口时省略自身，整页宽滚动祖先不能屏蔽窄侧栏。语义候选仍需达到最小宽度和窗口 35% 的高度，不要求左右区域等高。最多跨十六层无矩形或近等尺寸的透明 AXGroup 包装，在语义 landmark 边界停止，始终保留真实 AX 身份及祖先关系。几何推断的左右面板要求明显垂直重叠、高度及足够覆盖，窄侧栏不受父面积 8% 门槛限制；上下面板还要求 SplitGroup。小卡片内部的装饰分组不构成大区。语义列表使用视口裁剪，列表及 landmark 加入有限结构观察。别名先用矩形桶去重，再做有限相邻比较。选区保存 AX 对象身份，按 x/y 排序只影响呈现。

`AXLandmarkNavigation`、`AXLandmarkComplementary`、`AXLandmarkMain` 的通用平台映射依据 [W3C Core Accessibility API Mappings](https://www.w3.org/TR/2025/CRD-core-aam-1.2-20250327/)，不是按应用名、会话标题或 DOM 文本写特例。该语义规则本身不能证明某个具体应用公开了对应节点。

裸 AXList/AXContentList 可能是随滚动移动的内容分组，而非固定视口。当它位于已识别、同列的侧栏或滚动容器内时，以外层容器作为大区，避免列表分组移出视口后选区跳到主内容区。具有真实滚动属性的列表、原生 Outline/Table 仍可独立成为大区；没有可用外层面板的语义列表仍保留后备识别。新区域解析完成后，以真实祖先所属的区域矩形进一步裁剪候选，浮层使用自身裁剪。点击前对这些区域祖先重新读取边界，所需边界不可读时拒绝点击。

默认范围由祖先关系筛选选区内部与无区域归属的控件，浮层始终可选；Space 只改变这个集合的筛选条件。未扫描到、范围隐藏、浮层遮挡、预览待分配、几何页和编码冲突页在诊断中分别计数。每轮完成时另记录原选区是否保留、选择是否改变；覆盖统计附带会话/扫描序号、是否最终结果及选区自身候选数量，仍不记录应用名、控件正文或坐标。

## 行内操作按需展开

`AXNode.operable` 由启用状态和角色/动作决定，`VisualVisibility` 单独记录 visible / hidden / unknown。纯 AX 路径仅在明确隐藏时设置 hidden，未提供隐藏属性或返回 false 时仍为 unknown；屏幕内矩形和点击命中不会使它变为 visible。明确隐藏不发布候选；unknown 仍保留在扫描的原始目标集合中。

`RowDisclosure` 复用同一快照的角色、祖先与矩形，在布局队列建立展示分组，不增加 AX 遍历。优先明确的 Row/ListItem/OutlineRow；列表中普通 Group 包装的内容项要求位于真实列表后代、宽度至少为列表的 55%、高度小于列表的 85%，跳过整列包装及大区本身。最近的行祖先拥有子操作，嵌套行独立；以行本身或占行宽至少 60% 的最大可点击对象为主目标。按钮、弹出按钮和菜单按钮折叠，文本链接、复选框、输入控件保持可选；浮层不参与分组。无点击主目标时，以真实行 AX 身份创建 purpose=rowDisclosure 的悬停入口，点击路径明确拒绝该用途。

build 14 补充没有列表角色的三条结构路径：普通组或可点击容器中，主目标占行宽和高至少 60%，次要按钮处于同一纵向范围且相对较小；普通组有独立于按钮的静态文本、操作按钮，并与同父内容块纵向重复；主目标与操作平铺时，共同容器至少包含两个较宽且纵向分离的主目标，只归入同行且没有归属歧义的小按钮。重复内容块允许内部操作工具栏，独立工具栏和输入表单不推断为行。正文链接不折叠。几何阈值用于选择展示分组，不能证明透明或隐藏。透明/单子节点包装只在寻找共同父节点时归一化，悬停仍使用真实 AX 身份与矩形。

同一主目标的嵌套包装合并为一个展开入口，按钮只归属于一个最近的行，其他行的主目标不参与折叠。分组计时和结构计数在最终发布时记录，包含语义行、普通容器、独立正文块、分组来源及未分组操作数量；不保存树内容或坐标。所有推断在原快照上计算，不改变滚轮路由、扫描预算或额外发起 AX 调用。

build 15 将次要操作识别与扫描器已读出的动作信息对齐：三种按钮角色之外，普通 Group、Image 等通过 AXPress/AXPick 暴露的独立操作也可进入分组；仍需上述行结构依据。链接、静态文本、标题及带专用语义的输入/选择/展开控件，即使声明 AXPress 也不会作为次要按钮折叠。较宽的可点击文本或其他非标准主目标可作为行入口，不会被小操作按钮取代。诊断增加语义行实际拥有的候选数、可点击通用操作数及未分组数量，避免仅凭“分组为零”推断 AX 树结构。

默认展示主目标并收起行内操作。`;` 进入选行，完整行码或方向键加 Return 触发展开，按键自动重复不重复操作；关闭自动点击仍需 Return。控制器先用新的前台、窗口、矩形、裁剪和 AX 命中祖先验证悬停点，再发带标记的 mouseMoved，不发送 mouseDown/Up。约 140 ms 刷新及原有有限再发现展示该行操作，其他行继续收起。点击校验仍独立执行，不因展开而跳过。再次 `;` 收起，滚动、切区、输入、窗口变化清除展开；菜单出现时退出选行以保留浮层入口。没有可展开行时继续普通标签显示。

Space 显示原始全量 AX 目标，设置可关闭默认折叠。行与按钮编码仍按 AX 身份保存，折叠不会删除扫描候选或释放仍存在对象的编码。合成的行入口仍按选区和浮层遮挡过滤。诊断新增分组数量、折叠数量、未知可见性数量及展开/选行布尔状态，不记录名称、样式或坐标。此策略不声称识别了 CSS opacity，结构依据不足时仍可能无法分组，常显行内按钮也可能被折叠。

## 编码与分页

首次未完成扫描总共最多绑定六个重复短码。其余新目标等本轮最终发布；完整扫描先释放确认消失的对象，再按当前范围统一分配。未完成或预算截断不能证明对象消失。

每个窗口/会话维护 AX 身份到编码的映射。先使用整个窗口尚未占用的兼容码；仅扩展尚未发布的短码分支。已发布两位或三位码不可改名，全局可用空间耗尽后才复用并安全分页。

`LabelPages.geometry` 保存空间分页，`display` 保存编码互斥分页。后续布局只继承 geometry，避免稳定码冲突永久污染空间容量。布局先给小控件位置，再让宽行在自身矩形内搜索最多 16 个横向点与右端，最后尝试约 56 pt 的周边位置。隐藏页不能点击。

输入前缀期间不提交新编码、布局或页码，等前缀清空再提交。候选增加不会把唯一剩余的不完整前缀自动当作完整标签。

## 滚动与刷新

滚动位移使用单调时钟，首次事件立即投递；持续滚动取消扫描和布局、隐藏按钮，松开后 450 ms 再刷新。按住意图与几何有效性分离：有效区域确认后可接续，松开、系统中断、输入或退出都会取消旧意图。原选区未确认时不会把意图发送到临时发现的其他区域。

滚轮落点复用当前扫描的节点、祖先关系与可见裁剪，不额外查 AX。推断侧栏的大区范围可以包含固定顶部按钮；实际落点选在该区后代中可见面积最大的滚动/列表容器里，同面积时优先真实滚动容器。其他分支和浮层列表不能参与选择。扫描只读到面板而未读到其内容时，保留按住意图并继续扫描，避免先落到顶部再取消遍历。原生视口、独立列表和 WebArea 仍使用自己的滚动范围；落点先搜索内部网格，避开小型独立滚动后代与按钮，再寻找控件旁的空隙。gg/Home/End 的滚轮回退也使用这套路由。

需要时停放指针，退出/临时输入仅当指针仍在停放点 4 pt 内恢复。端点探测仅在滚动中，最多一个在途请求，至少 200 ms 间隔；无来源约 1 秒后再试。只接受滚动条范围或有界的溢出内容几何，不用时间或静止控件猜测。

前台 PID 取自 NSWorkspace 的键盘接收应用；不以 AX 全局焦点的瞬时差异退出同一导航。点击前再查这个前台 PID、窗口、对象、相交几何及祖先裁剪，自己的 CGEvent 带标记并透传。点击约 140 ms、应用快捷键约 220 ms 刷新；通知合并约 120 ms。过渡计划只有 650 ms 和 1.5 s 两个再发现截止点，阻塞时留到下次状态变化处理，不靠永久空闲轮询。

已知结构轻量检查最多 64 节点，每批 8 节点/约 12 ms。这个检查不能证明深层无新增区域，因此不会取消上述两次真正重新发现。临时不可读按 100/200/400/800/1,600/2,000 ms 退避。

系统 tap 停用先区分健康 tap 的迟到通知、主动闲置、超时和其他原因。超时仅在同一有效前台会话且权限仍有效时最多 10 秒恢复两次，清空旧滚动意图。主动停用通知不会再次触发递归停用。

## 视觉与性能口径

覆盖窗口逐显示器创建，使用 `.nonactivatingPanel`，明确不可成为 key/main 窗口、透明、不拦鼠标；AX/Quartz 顶部原点坐标与 AppKit 全局坐标显式转换。跨屏候选归相交面积最大的屏幕，所有屏幕共享分页。

字母标签使用可复用的 NSVisualEffectView，`.popover` 材质与 `.behindWindow` 合成只覆盖各自圆角矩形；浅色、深色及跟随系统的材质视图 alpha 为 62%。普通按钮叠加 6% 浅蓝白/深灰着色，选中按钮为 18% 薄荷绿；大区标签使用 28% 薄荷绿着色及柔和浅薄荷绿细边，明暗文字和前缀也统一为绿调。文字独立绘制、保持不透明。设置支持浅色、深色、茶色及跟随系统，并持久保存选择。茶色仍作为可选项保留：88% 暗材质上的按钮叠加 30% 茶褐色，选中态为 42% 浅琥珀色，配暖奶白字与香槟细边。小标签 6 pt、大区标签 8 pt 圆角，轻阴影不扩大布局命中区。系统减少透明度时关闭模糊，使用不透明底色，薄荷绿区域牌改用深色文字保证对比。无需录屏或抓取桌面像素；真实模糊由系统合成器完成，离屏图只验证正式视图结构和回退绘图。

区域无填充。高亮边框默认浅薄荷绿色 sRGB [0.66, 0.92, 0.81]，比字母牌着色更浅，原生颜色选择器仍可调整。当前区 1.4 pt/50%，其他区 0.6 pt/10%。当前区单条 opacity 动画 10 秒淡出、10 秒淡入；不逐帧读 AX。减少动态效果或设置关闭动画时静态显示。端点边 3 pt/55%，基础边框省去该边，避免透明度叠加。

`first_region` 是新几何可用于操作的时刻，`first_labels`/`all_labels` 是布局准备完成；`*_drawn` 是主线程 displayIfNeeded 完成。后者不代表显示器合成或目标应用刷新完成。

AX 调用耗时包括窗口/焦点入口读取，scan_work 包含遍历中的 IPC，二者不是可相加的互斥阶段。另记扫描纯计算、区域解析、去重、布局、编码、主线程发布。滚动报告输入回调到首次投递，以及 timer 间隔 p50/p95/max；目标应用画面更新未测量即标未知。冷/热/重复唤出必须人工标记实验条件，不从数字反推。
